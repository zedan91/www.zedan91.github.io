AZOBSS STAFF OWN SALES / COMMISSION RULES ADDON

Purpose:
- Admin can read/write all.
- Semi-admin/staff can only read their own sales/commission records.
- Semi-admin/staff can create/edit products only if they have permission.
- Products should store owner metadata:
  ownerUid, ownerUsername, ownerEmail, commissionRate:70, ownerShare:70, platformShare:30

Recommended purchaseLogs fields:
- ownerUid
- ownerUsername
- ownerEmail
- commissionRate: 70
- ownerShare: 70
- platformShare: 30

Rules concept to merge:

match /purchaseLogs/{purchaseId} {
  allow read: if isAdmin()
    || (
      request.auth != null
      && (
        resource.data.uid == request.auth.uid
        || resource.data.ownerUid == request.auth.uid
        || resource.data.createdByUid == request.auth.uid
      )
    );

  allow create: if request.auth != null
    && request.resource.data.uid == request.auth.uid
    && request.resource.data.status == "pending";

  allow update: if isAdmin();
  allow delete: if isAdmin()
    || (
      request.auth != null
      && resource.data.uid == request.auth.uid
      && resource.data.status == "pending"
    );
}

match /commissionRecords/{id} {
  allow read: if isAdmin()
    || (
      request.auth != null
      && (
        resource.data.ownerUid == request.auth.uid
        || resource.data.createdByUid == request.auth.uid
        || resource.data.uid == request.auth.uid
      )
    );

  allow create: if isAdmin();
  allow update, delete: if isAdmin();
}
