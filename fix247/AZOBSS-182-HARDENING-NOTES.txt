AZOBSS 182 - Receipt Token + Static Cache Hardening

Changes:
1. New Software/CAD premium orders now require receipt token by default.
   - New orders include receiptTokenRequired:true and receiptTokenVersion:2.
   - Old historical/fallback receipt records remain compatible unless AZOBSS_REQUIRE_RECEIPT_TOKEN=1 is enabled.

2. Download finalization preserves receiptTokenRequired for paid orders.

3. Static file cache headers improved.
   - HTML remains no-store so latest patch is loaded.
   - JS/CSS/JSON short cache with revalidation.
   - Images/fonts cache longer.
   - ZIP/EXE/MSI/PDF/TIF remain private/no-store.

No Firebase Rules update required.
