# SolatTime trial download

The small cart control beside SolatTime Buy Now is now a public download icon.
It downloads the unified v1.0.32 installer for the 30-day trial or reinstallation,
without requiring checkout or login. Licence purchasing remains on Buy Now;
the product's configured price and Support action are unchanged.

The icon is rendered with the card and excluded from cart binding, so search,
filtering and subsequent card updates cannot convert it back into a cart.
Other products retain their existing cart and download behavior.

Installer: https://files.azobss.com/solattime/releases/1.0.32/Azobss_SolatTime_Setup.exe

Existing private download routes, licence services, payment handlers and feeds
are unchanged. No environment variables or backend deployment are required.
