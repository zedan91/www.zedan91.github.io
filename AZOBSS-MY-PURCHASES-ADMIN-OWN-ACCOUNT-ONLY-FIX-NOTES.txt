AZOBSS PATCH 415 - My Purchases Admin Own Account Only Fix

Issue:
- Admin account could see other users' purchases inside My Purchases Pro.
- My Purchases is supposed to be an own-account purchase view.
- Admin should use Admin Dashboard > Payment Logs / Sales Overview to view all user transactions.

Root cause:
- Backend helper azMyPurchasesBelongsToIdentity() allowed admin bypass:
  if (identity.isAdmin) return true;

Fix:
- Removed admin bypass from customer My Purchases owner matching.
- /api/my-purchases now returns only current signed-in account records.
- Added backend response marker:
  scope: own-account-only
  patch: 415
- Changed My Purchases cache prefix from v382 to v415 so old admin all-user cache is ignored.
- Added frontend current-user filter for cached/backend/fallback rows.
- Updated modal note to clarify admin all-user view belongs in Payment Logs / Sales Overview.

Expected result:
- Admin zedan91 opening My Purchases only sees zedan91 purchases.
- Admin no longer sees zedan0002 or other users in My Purchases.
- Admin Dashboard Payment Logs / Sales Overview still shows all transactions as intended.

Based on:
- Patch 414 baseline.

Not changed:
- Subscription route diagnostic / verify endpoint from patch 413 remains.
- Live Streaming Tools category from patch 414 remains.
- Admin user role color + PA/BM dot remains.
- Lucky Draw and PA/BM payment/download logic not changed.
