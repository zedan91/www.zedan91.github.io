# Patch 813 — Device Type First Selection Lock

- Requires the customer to choose `Jenis peranti` before the `Jenama`, `Model peranti`, `Saiz skrin` and `Jenis skrin` fields can be used.
- The four dependent fields are visibly disabled on first load and become available immediately after a device type is selected.
- Brand and model autocomplete menus remain closed while their fields are disabled.
- For `Desktop PC`, brand and model become available, while screen size and screen type remain disabled because they are not applicable.
- Resetting the device type clears dependent model and screen selections to prevent mismatched booking data.
- Keeps all WhatsApp formatting, invoice, booking, quota-saving and other functions from patch 812.
