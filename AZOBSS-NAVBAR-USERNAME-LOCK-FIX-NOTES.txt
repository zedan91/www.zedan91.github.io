AZOBSS NAVBAR USERNAME LOCK FIX (334)
Date: 2026-06-24

Purpose:
- Fix navbar username sometimes changing from AZOBSS username to Gmail/Firebase display name.
- Keep top navbar display locked to official AZOBSS username.

Changed files:
- assets/js/azobss-global-auth.js
- main.js

Fix details:
1. Added official username resolver/lock helper:
   - prefers usernameKey / username / id
   - never uses Gmail displayName as main navbar label
   - never falls back to email prefix unless no official username exists
   - caches username by Firebase uid and email

2. saveUser() now normalizes the stored user:
   - usernameKey = official AZOBSS username
   - username = official AZOBSS username
   - name/displayName are also aligned to username to stop old scripts from overwriting navbar with Gmail name

3. syncHeader() now renders only locked AZOBSS username.

4. Added navbar guard:
   - if another legacy script changes #signedInName after render, it is corrected back to official username.
   - observes only text changes, not style/class, so it should not create blinking loops.

5. Email login improvement:
   - when login uses Gmail email, system no longer creates/uses email-prefix username as first choice.
   - it tries to resolve real username from Firestore/profile/locked mapping.

6. Lucky Draw main.js user display now uses same username lock helper.

No Firebase Rules update needed.
No Render deploy needed.
GitHub Pages deploy only.
