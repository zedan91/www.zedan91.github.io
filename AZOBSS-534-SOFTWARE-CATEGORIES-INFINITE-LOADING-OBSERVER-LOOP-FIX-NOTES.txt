AZOBSS Patch 534
Software Categories Infinite Loading / Observer Loop Fix
Date: 2026-07-20
Baseline: (533)-AZOBSS-SOFTWARE-SHARED-CARD-CONTENT-RAISE-FIX_20260720.zip

ROOT CAUSE
- Patch 532 reconciled the shared product card inside a MutationObserver.
- Every reconciliation executed more.textContent = 'More' even when the text was already identical.
- Replacing textContent creates a childList mutation.
- The same observer then called reconciliation again, creating a continuous loop.
- The browser main thread became busy and the page stayed at "Loading categories...".

FIX
- Only update the More button text when its value actually differs.
- The observer now reacts only when a .download-card, or a wrapper containing one,
  is newly inserted.
- Text-node and button mutations generated by reconciliation are ignored.
- Observer runs are coalesced through requestAnimationFrame.

PRESERVED
- Patch 533 logo/content vertical positioning.
- Shared product filtering and card layout.
- Firebase, Render backend, payment, download and promotional logic.
