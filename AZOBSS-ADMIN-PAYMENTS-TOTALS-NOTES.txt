AZOBSS ADMIN PAYMENTS & TOTALS PATCH

Added to /admin/:
- New sidebar tab: Payments & Totals
- Total purchase amount cards:
  PA/BM Total RM
  Software Total RM
  CAD Tools Total RM
  All Purchases RM
- Payment status summary:
  Pending
  Verified/Paid
  Total Records
- Latest payment / purchase records list
- Filter:
  All, PA/BM, Software, CAD Tools, Pending Only, Paid/Verified Only

Data source:
- purchaseLogs collection, latest 100 records.
- Category is inferred from productType/category/source/item/title fields.

No Firebase Rules change required if admin already has read access to purchaseLogs.
