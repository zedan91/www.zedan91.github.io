AZOBSS 187 - Software Stats API Protect + Abuse Guard

Baseline: (186)-AZOBSS-MANUAL-COMPLETE-PURCHASE-PROTECT-FIX_20260617.zip

Changes:
1. Added rate limits for Software Stats endpoints:
   - GET  /api/software-stats
   - POST /api/software-stats/download
   - POST /api/software-stats/like
   - POST /api/software-stats/rate
   - POST /api/software-stats/admin-set

2. Protected /api/software-stats/admin-set:
   - Requires Firebase admin ID token or AZOBSS_ADMIN_API_SECRET/AZOBSS_COMMISSION_API_SECRET.
   - Prevents public users from manually changing downloads, likes and rating totals.

3. Added request validation:
   - Reject blank productId for download/like/rate.
   - Reject invalid JSON body.
   - Clamp stats values to safe numeric ranges.

4. Admin-set audit field:
   - updatedBy is saved for manual stat edits.

No Firebase Rules update required.
No new Render ENV required.
Optional existing secrets can be used for API/admin scripts.
