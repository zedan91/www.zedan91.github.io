AZOBSS (591) — ADMIN PER-USER PRICE PERCENT ADJUSTMENT
Tarikh: 26 Julai 2026

FUNGSI BAHARU
- Admin boleh menetapkan pelarasan harga khas untuk setiap pengguna berdaftar.
- Lokasi: Admin Dashboard > Users > Registered User Records > Edit.
- Medan: Price Adjustment (%).

CARA NILAI DIGUNAKAN
- Nilai negatif = diskaun. Contoh: -20 bermaksud harga 20% lebih rendah.
- Nilai positif = kenaikan. Contoh: 15 bermaksud harga 15% lebih tinggi.
- Nilai 0 = harga asal.
- Julat dibenarkan: -99% hingga +500%.
- Harga akhir dibundarkan kepada 2 tempat perpuluhan dan minimum RM0.01.

SEKSYEN TERLIBAT
- PA/BM dan pilihan Lot Kadaster/NDCDB yang berkaitan.
- Pelan Akui untuk awam apabila pengguna berdaftar sedang log masuk.
- Software premium.
- CAD Tools premium.
- Pelan langganan/activation plan yang melalui checkout Software atau CAD.

TINGKAH LAKU PENGGUNA
- Pelarasan hanya digunakan kepada pengguna berdaftar yang log masuk.
- Pelawat/tetamu Pelan Akui awam kekal menggunakan harga awam asal.
- Harga yang dipaparkan pada butang dan harga pembayaran akhir menggunakan peratus pengguna tersebut.
- Troli PA/BM dikira semula selepas profil pengguna dan peratus harga selesai dimuatkan.

KESELAMATAN HARGA
- Backend Render membaca rekod pengguna daripada Firebase dan mengira semula harga akhir.
- Harga Software/CAD berpandukan harga produk dipercayai pada backend sebelum peratus pengguna digunakan.
- Nilai harga daripada browser tidak dijadikan sumber harga muktamad.
- Rekod pesanan menyimpan harga asas, harga jualan dan peratus pelarasan untuk audit.

MEDAN FIRESTORE PADA DOKUMEN USERS
- adminPriceAdjustmentOverride: true
- adminPriceAdjustmentPercent: nombor
- priceAdjustmentPercent: nombor
- priceAdjustmentManagedBy: "admin"

DEPLOYMENT

3. Firebase Rules tidak perlu diubah jika rules semasa sudah membenarkan admin mengemas kini dokumen users dan pengguna membaca profil sendiri.
