# AZOBSS v1288

- Software Promo and Monthly Lucky Draw on the right are now built-in entries in Homepage Banner Manager.
- Administrator can drag, resize, set X/Y/width/height, show/hide and save both right-side banners globally.
- Lucky Draw also supports changing image and destination link from the same manager.
- Software Promo keeps its automatic product image, price and per-product link from Software Tools; only layout/show-hide are managed here so the carousel is not broken.
- Admin editor panel automatically docks to the opposite side when a right-side banner is selected, keeping the selected banner reachable for drag/resize.
- Right-side banners are hidden until Firestore geometry has loaded, preventing default-size/position flash.
- Existing Exabytes/custom banner manager, centered social safe-zone, drag/resize and first-load flash fix are retained.
