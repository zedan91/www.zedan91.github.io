# AZOBSS v1343 — Dedicated Upgrade & Parts workspace

Baseline: v1342.

## Changes
- `Upgrade & Parts` in the PC & IT Services dropdown now opens `/Upgrade-Parts/` instead of scrolling to the orange card on `/PC-IT-Services/`.
- New dedicated page with estimated RM ranges for RAM, SSD/NVMe, GPU, PSU, laptop batteries and adapters.
- Added quick interactive component estimator and compatibility checklist.
- Added service references for SSD cloning (RM120) and cleaning + thermal paste (RM80, matching the current booking page).
- `PC-IT-Services` Upgrade card now uses `Lihat Harga & Upgrade` and opens the dedicated page.
- Updated static navbar links across website HTML and the dynamic `azobss-more-nav.js` menu to recognise `/Upgrade-Parts/` as its own active PC & IT Services section.
- Existing v1342 Affiliate Shop price sorting remains unchanged.

All displayed component prices are explicitly labelled as estimates and require final compatibility/stock confirmation.
