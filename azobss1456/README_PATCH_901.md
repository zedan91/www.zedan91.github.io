# AZOBSS Patch 901

## Software Key — buang badge "Lengkap"

- Membuang badge hijau `Lengkap` daripada rekod yang sudah mempunyai Key Serial kerana maklumat itu sudah jelas pada medan `KEY SERIAL`.
- Mengekalkan badge `Menunggu` hanya pada rekod yang masih belum menerima Key Serial supaya rekod yang memerlukan tindakan kekal mudah dikenal pasti.
- Mengekalkan tema navy gelap, format telefon Malaysia, susun atur kad, carian, susunan dan pagination baseline 900.
