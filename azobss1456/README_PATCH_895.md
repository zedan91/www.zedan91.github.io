# AZOBSS Patch 895 — Vertical Full-Width Software Key Cards

## Admin > Software Key

- Setiap kad Software Key kini menggunakan satu baris penuh dan disusun dari atas ke bawah.
- Kad tidak lagi dipaparkan sebelah-menyebelah pada desktop.
- `System ID`, `Systemcode`, `Motherboard ID` dan `Key Serial` dipaparkan sebaris pada desktop supaya kad lebih memanjang dan rendah.
- Pada skrin sederhana, empat medan berubah kepada dua lajur.
- Pada skrin telefon, semua medan berubah kepada satu lajur supaya nilai kekal mudah dibaca.
- Pagination tiga rekod setiap halaman dan semua fungsi daripada patch 894 dikekalkan.
