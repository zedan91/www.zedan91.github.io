# AZOBSS v1091 — Tempah Website One-Click WhatsApp UX

Baseline: v1090. Package version: `1.0.1091`.

## Tempah-Website UX improvements
- Final CTA changed to **Hantar Permintaan di WhatsApp**.
- One click opens WhatsApp to AZOBSS service number `601135600723` with the completed request message pre-filled; customer only needs to review and press Send.
- `Salin Maklumat` retained only as a backup option.
- Removed GitHub status/username questions from the initial request form. GitHub is explicitly deferred until after scope/quote confirmation.
- Fixed stale validation text that referenced the removed `Saya belum pasti` website type.
- Added a six-step **Apa yang berlaku selepas saya hantar?** roadmap: Request → Review → Quote/Timeline → Deposit → Preview → Revision/Launch.
- Added five concise FAQs covering domain, GitHub, missing logo/images, changing website choice, and deposit timing.
- Reframed the GitHub guide as a later step after the booking is confirmed.

No PA/BM, payment, cadastral download, backend, pricing, or authentication logic was changed in this patch.
