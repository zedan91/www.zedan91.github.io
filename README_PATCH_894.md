# AZOBSS Patch 894 — Customer Hierarchy & 3-Record Pagination

## Admin > Software Key

- Nama PC seperti `USER` atau `ADMINISTRATOR` dikecilkan dan dijadikan label ringkas.
- Nama pelanggan dan nombor telefon dipindahkan ke baris di bawah nama PC, dibesarkan dan ditebalkan untuk rujukan pantas.
- Tarikh dan masa dipaparkan sebagai dua maklumat berasingan.
- Spesifikasi PC dan Record ID dipindahkan ke baris metadata khas supaya tidak bercampur dengan tarikh atau masa.
- Senarai memaparkan maksimum tiga rekod bagi setiap halaman.
- Pagination hanya muncul apabila hasil carian mengandungi lebih daripada tiga rekod.
- Carian atau pertukaran susunan kembali ke halaman pertama secara automatik.
- `Pilih semua dipaparkan` kini hanya memilih tiga rekod pada halaman semasa.

## Kekal Daripada Patch 893

- Carian mengikut pelanggan, telefon, PC, System ID, Systemcode, key dan motherboard.
- Susunan mengikut tarikh, pelanggan, nama PC dan status.
- Edit maklumat pelanggan, salin nilai, delete, bulk delete dan Export CSV.
