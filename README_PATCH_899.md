# AZOBSS Patch 899 — Malaysian Customer Phone Spacing

## Admin > Software Key

- Nombor telefon mudah alih Malaysia diformat secara automatik untuk paparan yang lebih mudah dibaca.
- `01137446227`, `601137446227` dan `+601137446227` dipaparkan sebagai `+60 11-3744 6227`.
- Nombor mudah alih tujuh digit selepas prefix, contohnya `0192554232`, dipaparkan sebagai `+60 19-255 4232`.
- Format paparan yang sama digunakan dalam Export CSV.
- Nilai asal dalam rekod tidak diubah; carian menggunakan digit masih berfungsi.
- Tema kad gelap, susunan nama PC, format masa `AM/PM` dan pagination tiga rekod dikekalkan.
