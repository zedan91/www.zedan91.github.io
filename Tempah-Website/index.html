Proses memulakan projek

Pemilikan akaun, repository dan domain disusun atas nama customer supaya website lebih mudah diurus pada masa hadapan.

1

Sahkan skop dan deposit

  • Website satu halaman atau struktur lain
  • Bilangan produk atau pakej
  • Butang WhatsApp dan Telegram
  • QR pembayaran
  • Domain sendiri atau subdomain percuma
  • Harga, tempoh siap dan jumlah pembetulan
2

Sediakan bahan bisnes

  • Nama bisnes dan logo
  • Warna tema
  • Senarai produk serta harga
  • Gambar produk
  • Nombor WhatsApp dan Telegram
  • QR pembayaran, testimoni dan waktu operasi
  • Ayat “Tentang Kami”
3

Daftar akaun GitHub

  • Gunakan email bisnes sendiri
  • Pilih username berkaitan bisnes
  • Aktifkan 2FA
  • Simpan recovery code dengan selamat
  • Jangan berikan password GitHub
Lihat cara daftar langkah demi langkah ↓
4

Buat repository dan jemput collaborator

  • Cadangan repository: namabisnes.github.io
  • Pergi ke Repository → Settings → Collaborators → Add people
  • Masukkan username GitHub pembangun
  • Pembangun boleh mengemas kini website tanpa menggunakan password customer
5

Daftar domain atas nama customer

  • Contoh: empireshop.com, empireshop.my atau empireshop.online
  • Beli menggunakan akaun dan email pemilik bisnes
  • Beri akses DNS sahaja atau ikut panduan tetapan DNS
  • Versi demo boleh dibina sementara, tetapi website akhir sebaiknya berada dalam akaun customer

Permintaan website

Isi maklumat asas. Butang di bawah akan menyusun mesej, menyalinnya dan membuka WhatsApp AZOBSS.

Sebelum pembangunan bermula

  1. Skop, harga dan tempoh disahkan.
  2. Deposit dibayar mengikut persetujuan.
  3. Semua teks, logo, gambar dan pautan dihantar.
  4. Akaun GitHub dan domain menggunakan email customer.
  5. Jumlah pembetulan ditetapkan supaya proses lebih teratur.
Nota: Harga projek bergantung pada skop, jumlah kandungan, fungsi dan tempoh yang diminta.

Cara daftar akaun GitHub langkah demi langkah

Customer perlu menggunakan email bisnes sendiri. Akaun GitHub Free sudah memadai untuk menyediakan repository awam dan menerbitkan website statik melalui GitHub Pages.

1

Buka halaman pendaftaran

Tekan butang Daftar GitHub Sekarang di bawah atau pergi ke halaman Sign up GitHub.

2

Masukkan email bisnes

Gunakan email yang dimiliki dan boleh diakses oleh pemilik bisnes. Elakkan menggunakan email pembangun website.

3

Cipta kata laluan

Gunakan kata laluan yang kuat, unik dan tidak digunakan pada akaun lain. Simpan dalam password manager yang dipercayai.

4

Pilih username bisnes

Pilih nama yang mudah dikenali, contohnya empireshop. Username ini akan digunakan untuk profil dan boleh digunakan dalam alamat repository.

5

Lengkapkan pengesahan

Ikut arahan semasa pada skrin, termasuk pengesahan bahawa pengguna ialah manusia dan pilihan komunikasi jika dipaparkan.

6

Sahkan alamat email

Buka inbox email bisnes, cari mesej daripada GitHub dan tekan pautan pengesahan. Email yang disahkan diperlukan untuk menggunakan fungsi penting seperti mencipta repository.

7

Log masuk dan semak username

Selepas akaun aktif, log masuk dan tekan gambar profil di penjuru kanan atas. Username akan kelihatan pada profil. Hantar username sahaja kepada pembangun.

8

Aktifkan 2FA

Pergi ke gambar profil → Settings → Password and authentication → aktifkan Two-factor authentication. Gunakan aplikasi authenticator jika sesuai.

9

Simpan recovery codes

Muat turun atau salin recovery codes dan simpan di tempat selamat. Kod ini diperlukan jika telefon atau aplikasi authenticator tidak boleh digunakan.

10

Maklumkan kepada AZOBSS

Hantar username GitHub kepada AZOBSS. Selepas itu, repository boleh disediakan dan customer boleh menjemput AZOBSS sebagai collaborator tanpa berkongsi kata laluan.

Selesai: Akaun GitHub customer sudah bersedia. Maklumat yang perlu dihantar kepada AZOBSS hanyalah username GitHub.
Keselamatan: Jangan hantar password, kod 2FA atau recovery codes kepada sesiapa. Semua maklumat keselamatan mesti disimpan oleh pemilik akaun.
