AZOBSS 183 - ToyyibPay callback verify + safer logs

Changes:
1. ToyyibPay paid callback now verifies payment with ToyyibPay getBillTransactions before marking order as paid.
2. If verification is not paid yet, backend returns received/verification pending and does not create download token or commission record yet.
3. Emergency fallback is available with AZOBSS_VERIFY_TOYYIB_CALLBACK=0, but production should keep default ON.
4. Sensitive backend logs are reduced: email is masked, download URL is logged as host/path info only, download token is masked.
5. No Firebase Rules change is required.

Recommended Render ENV: none required.
Optional emergency only: AZOBSS_VERIFY_TOYYIB_CALLBACK=0
