# AZOBSS Baseline 910

- Menukar butang `Repair PC` pada sticky bar kepada dropdown bergaya sama seperti menu `More`.
- Menambah pilihan **Servis PC & Laptop** untuk pembaikan fizikal, format dan servis kedai.
- Menambah pilihan **Troubleshoot PC Online** untuk bantuan Windows dan software secara remote.
- Dropdown boleh dibuka melalui hover, klik/tap dan papan kekunci serta menandakan halaman aktif.
- Mengekalkan satu butang `Repair PC` sahaja pada sticky bar supaya navigasi kekal kompak.
