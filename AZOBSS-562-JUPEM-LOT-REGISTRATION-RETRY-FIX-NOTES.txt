AZOBSS PATCH 562 - JUPEM LOT REGISTRATION RETRY FIX
Date: 2026-07-24
Baseline: www.zedan91.github.io(33).zip

Problem fixed
- Intermittent popup: "JUPEM did not register the selected lot product."
- JUPEM could successfully accept the lot registration, but AZOBSS ignored the purchase-form submission response and only searched for a newly visible cart row.
- Slow JUPEM cart updates, expired login sessions, existing cart items, and small HTML formatting changes could cause false failures.

Changes
1. Read and validate the actual purchase-form submission response, URL and HTTP status.
2. Detect success from both product response and submitted transaction response.
3. Detect expired JUPEM login pages during the before-cart, product, submission and after-cart stages, then re-login once automatically.
4. Increase cart verification from about 7 seconds to about 28 seconds.
5. Accept a matching item already present in the JUPEM cart without deleting the pre-existing item.
6. Continue to the authoritative ZIP download verification when JUPEM accepted the submission but its cart row is delayed or not visible yet.
7. Make AddQuantity cart-row parsing tolerant of spacing and quoted/unquoted values.
8. Keep the cart mutation lock and only clean up a row that AZOBSS itself newly added.
