AZOBSS 485 - Similar Software Categories Merge

- Consolidated overlapping categories from about 61/63 labels to 35 broader professional categories.
- Internet + Web Browsers -> Internet & Browsers.
- Backup & Imaging + Backup & Recovery -> Backup & Recovery.
- System Utilities, Drivers, Cleanup, Rescue and Search/Launchers -> System Utilities & Maintenance.
- Download Managers, Video Downloaders and Torrent Clients -> Downloads & Torrents.
- Remote Tools + Remote & Server Admin -> Remote Access & Server.
- Media, Video Editing, Audio, Screen Capture and Live Streaming -> Audio, Video & Media.
- Graphic Design + Fonts -> Design & Typography.
- Office, General, Projects and Notes -> Productivity & Office.
- PDF + OCR -> PDF, OCR & Scanning.
- Similar developer, security, file/cloud, education, CAD/3D and games/emulator categories also merged.
- Existing Firestore items are mapped at runtime; no database migration is required.
- Bundled directory JSON categories are permanently consolidated.
- Firebase Rules and Render backend unchanged.
