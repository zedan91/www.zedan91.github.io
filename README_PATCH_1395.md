# AZOBSS v1395 — Admin Remote Support File Manager

Date: 2026-10-23

## Changes

- Adds an Administrator-only file manager inside `Troubleshoot-PC-Online/` for the UltraViewer Remote Support BAT.
- Administrator can upload/replace the active `.bat` and delete the active file without rebuilding the full website.
- Uploaded file bytes are stored privately in Cloudflare R2 through the existing signed upload gateway.
- Public users only see the normal download button; the admin controls are hidden.
- Public downloads use a short-lived signed R2 URL generated by the backend.
- Backend verifies the real Firebase Administrator token for upload/register/delete actions; hiding the UI is not the security boundary.
- Replacing an existing managed BAT attempts to remove the previous R2 object automatically.
- If no managed file has ever been configured, the current static BAT remains as a legacy fallback. After an Administrator deletes the managed file, the public download button becomes unavailable until a new BAT is uploaded.

## Endpoints

- `GET /api/remote-support-file/status`
- `GET|POST /api/remote-support-file/download`
- `POST /api/remote-support-file/admin-upload-token` (Administrator only)
- `POST /api/remote-support-file/admin-register` (Administrator only)
- `POST /api/remote-support-file/admin-delete` (Administrator only)

## Storage

Active-file metadata is persisted in Firestore at `settings/remoteSupportFile`, with a local backend fallback metadata file for development/runtime fallback. File bytes are kept in Cloudflare R2.
