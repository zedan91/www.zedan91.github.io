AZOBSS PATCH 214 - PA/BM User/Admin Panel Leak Fix

Root cause:
- zedan0001 was hardcoded as admin in several PA/BM/frontend admin detectors.
- The PA/BM page uses one wrapper (#adminPurchasePanel) for both admin Purchase Records Users and user Latest Purchase List.
- When body.is-admin was toggled by old scripts/cache, normal user mode could show the owner/admin purchase summary UI.

Fix:
- Removed zedan0001 from hardcoded admin username lists.
- Added owner-admin-only class guard: body.pabm-owner-admin.
- Purchase Records Users, admin tools, admin summary list, reset controls, and admin pagination are shown only for zedan91/zedan9107 owner admin.
- Normal members only see Latest Purchase List.
- Added repeated guard + MutationObserver to prevent older scripts from re-showing the admin records block.

No Firebase Rules update required.
No Render ENV required.
