AZOBSS Backend ToyyibPay Dynamic + Email Download Fix

Changed backend/server.js:
- Added CORS before payment API routes so browser fetch will receive proper JSON response.
- Added /api/toyyib/create-bill dynamic ToyyibPay response support for frontend.
- Added Gmail/Brevo SMTP email sender using nodemailer.
- After ToyyibPay payment is verified/callback received, backend generates a unique download token and emails it to buyer.
- Download link now auto-expires after first access/download.
- Added receipt URL generation.
- Removed old duplicate legacy ToyyibPay route that could cause confusion.

Required Render env:
TOYYIB_SECRET_KEY
TOYYIB_CATEGORY_CODE
PUBLIC_BASE_URL=https://azobss-backend.onrender.com
FRONTEND_BASE_URL=https://www.azobss.com
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=yourgmail@gmail.com
SMTP_PASS=GOOGLE_APP_PASSWORD
MAIL_FROM=yourgmail@gmail.com

After upload/deploy:
1. Push this ZIP/code to GitHub/backend repo.
2. Render > azobss-backend > Manual Deploy > Deploy latest commit.
3. Test /api/health.
4. Test website Open Payment again.
