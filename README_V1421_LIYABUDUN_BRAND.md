# Liyabudun — formerly AZOBSS SolatTime

The owner selected Liyabudun as the product name; AZOBSS remains the publisher.
Desktop v1.0.39, visible catalogue/admin/buyer labels, product page and new
purchase emails use the new name. Existing cloud catalogue entries are rendered
with the new label without rewriting stored items or customer history.

AZSW-372165, solattime fulfilment markers, API paths, collections, serial format,
encryption context and signing keys remain unchanged. Old product names and
the new name resolve to the same licensed product. New checkout summaries use
Liyabudun after trusted catalogue validation; price and quantity checks are intact.
Each paid unit still gets its own serial. No existing licence/trial is reissued.

Installer filenames, signed feed paths and /solattime/ URL are deliberately
compatible with existing installations. Website ZIP is complete, not a patch.
