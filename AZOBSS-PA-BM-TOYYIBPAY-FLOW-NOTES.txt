AZOBSS PA/BM ToyyibPay Flow Update

Changes made:
1. Removed Maybank QR/manual bank payment UI from PA/BM purchase records payment panel.
2. Added Pay with ToyyibPay button.
3. Frontend calculates current unpaid PA/BM purchase records total after reset map.
4. Frontend sends PA/BM item records to backend endpoint:
   POST /api/toyyib/create-pa-bm-bill
5. Backend recalculates total from submitted PA/BM items and creates ToyyibPay bill using that total.
6. ToyyibPay bill amount uses total purchase amount, e.g. Total RM77 -> billAmount 7700 sen.

Important Render environment variables required:
- TOYYIB_SECRET_KEY
- TOYYIB_CATEGORY_CODE
- PUBLIC_BASE_URL or FRONTEND_BASE_URL recommended
- TOYYIB_CALLBACK_URL optional
- TOYYIB_RETURN_URL optional

Security note:
This patch validates PA/BM items server-side and recalculates amount in backend from the item list before creating ToyyibPay bill. For full maximum security, connect Firebase Admin service account to Render and make backend fetch purchaseRecords directly from Firestore by uid/usernameKey.
