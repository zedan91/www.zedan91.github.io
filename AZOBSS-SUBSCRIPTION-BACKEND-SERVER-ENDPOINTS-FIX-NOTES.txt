AZOBSS PATCH 412 - Subscription Backend Server Endpoints Fix

Issue:
- https://azobss-backend.onrender.com/api/subscription/verify still returned "File Not Found".
- This means the live Render backend is likely running backend/server.js, while patch 411 placed the full subscription API mainly in deploy-server.js.

Fix:
- Mirrored subscription API into backend/server.js:
  - GET/POST /api/subscription/verify
  - POST /api/subscription/admin/create-code
  - GET /api/subscription/admin/list
  - POST /api/subscription/admin/reset-device
  - POST /api/subscription/admin/revoke
  - POST /api/subscription/admin/extend
- Added same license rules:
  - 1 activation code = 1 active device
  - transfer_required for new PC
  - confirmTransfer=true transfers to new PC
  - old PC revoked when online verify again
  - transfer limit 3 per year
  - offline grace 3 days
- Backend/server.js payment flow now accepts subscription-code products even without a download link.
- Backend/server.js can auto issue activation code after ToyyibPay payment becomes paid.
- Paid response includes activation code fields if available.

After deploy test:
- Open:
  https://azobss-backend.onrender.com/api/subscription/verify
- Expected JSON:
  { "ok": false, "valid": false, "status": "missing_code", "error": "Activation code is required." }
- If it still says File Not Found after this patch, Render is running another file/service not included in this ZIP.
