AZOBSS Lucky Draw Prize Persistent Storage Patch (156)

Tujuan:
- Hadiah Lucky Draw tidak hilang walaupun ZIP website diextract semula ke repo GitHub.
- Tajuk, description dan image URL disimpan melalui backend Lucky Draw.
- Gambar boleh guna URL kekal dari Cloudinary / Firebase Storage / CDN.
- Admin masih boleh Load Prize JSON dan Export Prize JSON sebagai backup manual.

Perubahan Frontend:
- Tambah field "URL gambar kekal" pada Admin Edit Hadiah Lucky Draw.
- Tambah button "Sync from Backend".
- Tukar "Download JSON" kepada "Export Prize JSON".
- Tukar "Load JSON" kepada "Load Prize JSON".
- Save Prize akan hantar title, description, imageUrl dan optional file upload ke backend.

Perubahan Backend:
- Endpoint POST /api/lucky-draw/prize menyimpan imageStorage.
- Jika CLOUDINARY_CLOUD_NAME dan CLOUDINARY_UPLOAD_PRESET diset, file image upload akan dihantar ke Cloudinary dan backend simpan secure_url.
- Jika Cloudinary tidak diset, fallback masih simpan ke /uploads/lucky-draw seperti sebelum ini.

Env Cloudinary untuk Render backend:
- CLOUDINARY_CLOUD_NAME=nama_cloud_kamu
- CLOUDINARY_UPLOAD_PRESET=unsigned_upload_preset_kamu
- CLOUDINARY_FOLDER=azobss/lucky-draw   (optional)

Nota penting:
- Untuk long term paling kemas, guna Cloudinary/Firebase Storage/CDN URL di field "URL gambar kekal" atau set Cloudinary env di Render.
- Jika Cloudinary tidak diset dan hanya upload ke backend /uploads, gambar mungkin hilang jika hosting backend reset tanpa persistent disk.
- Export Prize JSON boleh jadi backup manual jika perlu restore.
