# AZOBSS v1101 — PA/BM/SBM Size Alignment

Based on v1100.

## Changes
- Aligns the desktop PA form vertical sizing with BM/SBM.
- PA form top spacing is reduced from the legacy 22px to the same 14px used by BM/SBM.
- PA input padding is matched to BM/SBM (12px 13px).
- Keeps the compact v1099 layout and animated map-search loading from v1100.
- Mobile layout is unchanged.
- No backend/API/payment/cart logic changes.

## Deployment
Frontend/static deployment only. Render backend redeploy is not required.
