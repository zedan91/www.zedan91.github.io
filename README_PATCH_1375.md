# AZOBSS v1375 — Ebook Comfortable One-Screen Desktop

## Tujuan
- Membetulkan v1374 yang terlalu kecil pada desktop.
- Kekalkan sasaran workflow **Pantas** muat dalam satu viewport desktop tanpa page-scroll panjang.
- Gunakan ruang kosong bahagian bawah untuk pulihkan saiz tulisan, input dan butang yang lebih selesa.

## Perubahan UI Ebook
- Hero/title, penerangan dan flow 01–04 dibesarkan semula.
- Card Asas Projek, Arah Penulisan dan Skala Ebook guna padding serta typography sederhana.
- Input/select, pilihan Pantas/Pro dan pilihan kedalaman dibesarkan.
- Panel Arahan AI Siap Guna dan action buttons turut dibesarkan.
- Layout dua baris desktop v1374 dikekalkan supaya masih compact tanpa kembali kepada halaman panjang.
- Emergency extra-tight mode kini hanya digunakan pada viewport desktop yang benar-benar rendah (<=720px), bukan <=850px.

## Compatibility
- Hanya styling Ebook desktop diubah.
- Prompt engine, RM19 lifetime access, ToyyibPay, saved prompt, direct #ebook performance fast-route, PA/BM dan modul website lain dikekalkan.
