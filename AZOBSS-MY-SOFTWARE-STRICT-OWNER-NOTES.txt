AZOBSS MY SOFTWARE STRICT OWNER FILTER FIX

Fixed:
- My Software filter now uses strict owner matching only:
  UID fields: ownerUid / createdByUid / staffUid / sellerUid
  Username fields: ownerUsername / createdByUsername / staffUsername / sellerUsername
  Email fields: ownerEmail / createdByEmail / staffEmail / sellerEmail

Important:
- It no longer uses broad fallback fields such as usernameKey/email/createdBy/updatedBy.
- It no longer allows static/default software to appear inside My Software.
- semiAdmin/staff only sees software they personally added after owner metadata exists.
- Old software without owner metadata must be edited & saved once to assign owner.
