# AZOBSS v1364 — Registered Users Unified Cards + Rank Badge

## Registered User Records
- All user cards now use the same neutral AZOBSS card background and border.
- Role/rank is no longer communicated by colouring the whole card.
- A compact rank badge is pinned at the upper-left/left edge of every username row:
  - 👑 ADM — Administrator
  - ◆ MGR — Manager
  - ★ STF — Staff
  - ● USR — User
- Badge accent colour is role-specific while the card itself remains visually consistent.
- Previous role colour wash and role-coloured left border are disabled.
- Redundant `Role: ...` pill is removed from Access & Status because rank is now owned by the badge.
- PA/BM, Membership, Tempahan and non-default pricing badges remain unchanged.
- Email grouping, login method badge, Firebase UID, search, pagination and Edit/Delete actions from v1363 remain unchanged.

## Deployment
- Frontend/Admin only. Existing v1360 backend can remain.
