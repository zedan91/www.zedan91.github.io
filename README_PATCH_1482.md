# AZOBSS v1482 — Retailer-only PC Builds + Clean Product Names

- Removed AZOBSS as a selectable PC Build source.
- Public PC Builds now contain retailer/source products only; AZOBSS live base builds remain internal for Build Sendiri calculations and are never merged into the public grid.
- Removed retailer/store-name prefixes from product names (for example IDEALTECH Radiance Rush -> Radiance Rush, DOTATECH FA-GAMING R5 -> FA-GAMING R5).
- Store identity remains visible through source/badge/admin metadata.
- Product-name cleaning is applied both to current retailer JSON and at runtime to protect future catalog refreshes.
- v1481 Hardware Shop/cart modal recovery, strict verified pricing, pagination, deferred invoice flow and Courier address validation remain intact.

This is a full root-ready package.
