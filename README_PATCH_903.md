# AZOBSS Patch 903 — Bantuan Windows Online

- Menambah servis **Bantuan Windows Online** dengan anggaran bermula RM30.
- Menambah kad harga dan pilihan servis online/remote pada halaman Tempah Servis IT.
- Apabila servis online dipilih sendirian, alamat, radius lokasi, penghantaran dan arah ke kedai tidak lagi diperlukan.
- Menyokong anggaran, rekod backend, notifikasi admin dan mesej WhatsApp untuk mod online.
- Jika servis online digabungkan dengan servis fizikal lain, syarat lokasi dan kaedah serahan fizikal digunakan semula secara automatik.
