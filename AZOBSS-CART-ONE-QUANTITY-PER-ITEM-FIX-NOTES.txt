AZOBSS PATCH 421 - Cart One Quantity Per Item Fix

Request:
- Add to Cart should allow only 1 quantity for each item/product.

Fix:
- Software/CAD cart now clamps every item to qty: 1.
- Pressing Add to Cart for the same product again no longer increases quantity.
- Old localStorage cart items with qty > 1 are automatically normalized back to qty 1.
- Cloud cart merge also keeps qty 1 per product.
- Plus (+) button in cart is disabled and cannot increase quantity.
- Minus (-) removes the item because quantity is fixed to 1.
- Cart badge counts unique items, not total duplicated quantity.
- Checkout total uses unique items only.

Affected:
- Software Tools cart
- CAD Tools cart
- Shared/global cart panel script
- Home fallback cart script
