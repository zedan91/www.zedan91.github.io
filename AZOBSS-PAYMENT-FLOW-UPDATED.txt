AZOBSS Payment Flow Updated

1. Open Payment
2. Complete Payment
3. Payment Verified
4. Download Ready

Changes:
- Submit Proof button removed from premium purchase popup.
- Payment opens in the same tab, not a new tab.
- Guest buyer must enter valid email before Open Payment.
- Last checkout page is stored in localStorage key: azobss_last_checkout_page.
- ToyyibPay return URL should be set to the page user should return to, e.g. https://www.azobss.com/Software-Tools/
