# Prize image preview

Click or keyboard-activate the Lucky Draw prize image to open a centered, larger
image with its title and full description. The preview uses the existing prize
carousel, including the current image and counter; previous/next controls and
left/right arrows navigate the same images. Single images hide carousel controls.

Close using the close button, Escape, or a click outside the dialog. Focus returns
to the prize image, background scrolling is paused while open, and mobile screens
stack the image above the scrollable description. Descriptions use only the
already-rendered safe text and links from the prize card.

This is a frontend-only change. Campaign rules, participation, prize settings,
backend, payment and licence behavior are unchanged.
