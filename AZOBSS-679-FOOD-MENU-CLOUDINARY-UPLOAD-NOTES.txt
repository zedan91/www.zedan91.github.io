AZOBSS PATCH 679 — FOOD MENU CLOUDINARY UPLOAD
Date: 31 July 2026
Baseline: (678)-AZOBSS-FOOD-MENU-IMAGE-ADMIN-EDITOR-FIX_20260731.zip

CHANGES
1. Removed Firebase Storage from the food menu image editor.
2. Images are uploaded directly to Cloudinary using an Unsigned Upload Preset.
3. Admin or users with Tempahan Makanan access ON can enter:
   - Cloud name
   - Unsigned upload preset
   - Cloudinary folder (default: azobss/food-menu)
4. Uploaded Cloudinary secure_url, public_id and asset_id are saved in Firestore foodMenuConfig/brownies.
5. “Padam dari website” removes the image from the website and Firestore list.
6. The original asset remains in Cloudinary and can be permanently deleted in Cloudinary Console using its Public ID.
7. Existing menu name, price, 4-inch availability, menu hide/restore and original image hide/restore functions are preserved.

RULES
Publish only:
FIREBASE-RULES-MERGED-FOOD-MENU-679-CLOUDINARY.txt

Firebase Storage Rules are NOT needed for this patch.

CLOUDINARY SECURITY
- The upload preset must be UNSIGNED because upload happens from the browser.
- In Cloudinary Console, restrict allowed formats to jpg, jpeg, png and webp.
- Set max file size to 5 MB or lower.
- Use a dedicated preset for AZOBSS food menu images.
- Never put Cloudinary API Secret in website code or Firestore.

NO CHANGES
No changes to Stripe, ToyyibPay, Software/CAD payments, food order records or existing access mapping.
