AZOBSS CART 2 MONTH RESET + LOGIN RESTORE OVERWRITE FIX

Root cause:
After cache/site data is cleared, user localStorage is empty. During login, before Firestore getDoc(userCarts/{uid}) finishes, a cart UI update event could call pushCloud() with an empty local cart and overwrite Firestore items with [].

Fix:
- Added cloudPulling/cloudReady guards.
- pushCloud() is blocked until Firestore pull finishes.
- Firestore cart is loaded first, then UI refreshes.
- 60-day expiry is applied safely to cloud items during pull.
- Old expired items are removed only after cloud data is loaded, not before.

Firebase Rules:
No new rules needed.
