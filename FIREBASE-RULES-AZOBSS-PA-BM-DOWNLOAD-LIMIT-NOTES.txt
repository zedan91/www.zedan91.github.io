PA/BM DOWNLOAD LIMIT RULES NOTE

Untuk fungsi limit download 5 kali + tempoh sah 7 hari, Firestore Rules sedia ada yang paling sesuai ialah:

match /purchaseLogs/{purchaseId} {
  allow read: if isAdmin()
    || (request.auth != null && resource.data.uid == request.auth.uid);

  allow create: if request.auth != null
    && request.resource.data.uid == request.auth.uid
    && request.resource.data.status == "pending";

  // User tidak boleh update sendiri status/downloadCount/expiresAt.
  // Backend Render menggunakan Firebase Admin SDK untuk set paid dan update downloadCount.
  allow update: if isAdmin();

  allow delete: if isAdmin()
    || (
      request.auth != null
      && resource.data.uid == request.auth.uid
      && resource.data.status == "pending"
    );
}

Penting:
- Jangan benarkan user update purchaseLogs sendiri.
- downloadCount, maxDownloads, downloadExpiresAtMs hanya dikemaskini oleh backend/admin.
- Backend Admin SDK bypass Firestore Rules, jadi ia masih boleh update downloadCount selepas user tekan Download.
