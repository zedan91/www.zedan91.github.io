AZOBSS PATCH 327 - SOFTWARE/CAD DESC BLINKING OBSERVER FIX

Issue:
- Button More and description appeared blinking/flickering after patch 326.

Root cause:
- The 326 runtime script used MutationObserver with attributes:true on class/style.
- The same script repeatedly wrote inline style attributes to cards/descriptions/buttons.
- This created a self-trigger loop: style update -> observer fires -> style update -> observer fires.

Fix:
- Changed the observer to watch childList/subtree only.
- The script still applies after initial render and when new cards are inserted, but no longer retriggers on its own inline style updates.
- Applied to root index fallback, /Software-Tools/, and /CAD-Tools-&-Resources/.

Firebase Rules: no update required.
Render backend: no deploy required.
GitHub Pages deploy only.
