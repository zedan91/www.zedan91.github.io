AZOBSS PA/BM auto sync selepas payment fix

Dibuat:
1. Latest Purchase List auto refresh selepas ToyyibPay return.
2. Tidak perlu refresh manual di phone untuk nampak rekod terbaru.
3. PC dan phone baca purchaseTotalResetAt dari Firestore user doc, bukan localStorage sahaja.
4. Item yang status paid/success/completed/settled terus jadi Download.
5. Pending Payment lama tidak override paid/reset.
6. Realtime listener untuk purchaseLogs dan user doc ditambah supaya browser lain sync ikut Firestore.
7. Popup payment success kekal dan button Go to Latest Purchase List scroll ke senarai pembelian.

Nota:
- Jika backend ToyyibPay boleh update purchaseLogs status = paid, semua browser akan sync lebih cepat.
- Jika backend hanya return ke frontend, user doc reset masih digunakan sebagai fallback supaya PC juga boleh detect paid.
