AZOBSS PA/BM JUPEM SESSION + BROWSER FALLBACK FIX (206)

Fixes paid PA/BM download cases where payment is already paid but JUPEM server-side proxy returns:
- PA file is temporarily unavailable from JUPEM
- BM/SBM file is temporarily unavailable from JUPEM

Changes:
1. Backend JUPEM fetch now retries with a scoped JUPEM session cookie.
   This helps when JUPEM returns HTML/session pages to server-side requests without cookies.

2. If backend proxy still cannot fetch the file, backend returns a browser-direct fallback URL.
   The frontend opens the original JUPEM download URL in the browser instead of showing a false unavailable alert.

3. Download counter is still guarded by the paid purchase record.
   For browser fallback mode, the attempt is counted when the fallback URL is issued.

4. Frontend PA/BM download handler can now detect JSON fallback responses and open the download URL.

No Firebase Rules update required.
No required Render ENV.
Optional emergency ENV:
AZOBSS_DISABLE_PABM_DIRECT_FALLBACK=1
