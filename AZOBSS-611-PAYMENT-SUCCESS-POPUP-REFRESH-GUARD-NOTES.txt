AZOBSS (611) Payment Success Popup Refresh Guard

Fixes:
1. Payment success popup no longer appears merely because old ToyyibPay callback parameters remain in the URL.
2. Popup is shown only after /api/verify-payment confirms the current return as paid.
3. Each verified order/bill callback is consumed once and recorded in localStorage.
4. ToyyibPay callback parameters are removed from the address bar after paid, failed, or already-consumed returns.
5. Duplicate checks from the two shared Firebase/auth modules are locked so only one verification runs at a time.
6. Pending orderId and billCode are cleared after completion.
7. Refreshing the PA/BM page alone cannot reopen the success popup.

Deployment: frontend only. Update GitHub Pages. Render backend and Firebase Rules do not need changes.
