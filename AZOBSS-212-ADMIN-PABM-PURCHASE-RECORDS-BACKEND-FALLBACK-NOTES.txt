AZOBSS Patch 212 - Admin PA/BM Purchase Records Backend Fallback

Fix:
- Admin Purchase Records Users could show "No purchase records yet" when frontend Firestore collection read was blocked/empty after security hardening.
- Latest Purchase List for a single user still showed records because it used user-scoped reads.

Changes:
- Added protected backend endpoint GET /api/admin/pa-bm-purchase-records.
- Endpoint uses Firebase Admin SDK to read purchaseLogs and compatibility users/{username}.purchaseRecords.
- Frontend admin Purchase Records now falls back to backend API with Firebase ID token when direct Firestore read returns no rows.
- Patched both azobss-global-auth.js and azobss-firebase-live-likes-sync.js.

Firebase Rules: no update required.
Render ENV: no new required.
