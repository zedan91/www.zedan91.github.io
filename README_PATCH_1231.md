# AZOBSS v1231 — Hide Sales Partner Application For Staff

- `Become an AZOBSS Sales Partner` is now shown only to ordinary users who can still apply.
- Staff, Manager, Administrator and other staff-like roles no longer see the entire Sales Partner application section.
- Approved applications also hide the entire section immediately, even before a refreshed local role is available.
- Pending applications continue to show `Application Pending`.
- Rejected applications continue to show `Reapply`.
- Added `administrator` role recognition alongside existing admin/staff role aliases.
- No Firestore Rules change is required from v1228.
