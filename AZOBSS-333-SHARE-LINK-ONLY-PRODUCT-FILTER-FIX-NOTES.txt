AZOBSS PATCH 333 - SHARE LINK ONLY PRODUCT FILTER FIX

Purpose:
- Fix issue after patch 332 where opening a shared product link no longer blinked, but sometimes all Software/CAD cards were visible instead of only the shared product.

Root cause:
- The 332 idempotent guard skipped re-applying the hide state when pagination/render scripts later restored card display.
- Pagination also needed to respect the shared-link hidden marker.

Changes:
- Replaced share-link filter JS in Software-Tools and CAD-Tools-&-Resources with stable v333.
- Re-enforces hidden state on every safe run without triggering search input/render loops.
- Adds data-az-shared-hidden marker and inline display none only for non-matching cards.
- Supports product/productId/id query params.
- Checks card dataset + child button data-product-id/data-product-name for matching.
- Pagination now ignores shared-hidden cards and listens for azobss-shared-product-filtered.

Deploy:
- GitHub Pages only.
- Firebase Rules update: not required.
- Render backend deploy: not required.
