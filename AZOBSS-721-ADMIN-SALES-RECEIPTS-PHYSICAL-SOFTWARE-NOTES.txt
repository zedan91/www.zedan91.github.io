AZOBSS PATCH 721
Admin Sales & Receipts — Physical, Software, CAD, PA/BM and Service
Date: 2026-08-03
Baseline: Patch 720

URL
- https://www.azobss.com/admin/
- New sidebar tab: Sales & Receipts

FEATURES
1. Unified sales ledger inside Admin Dashboard.
2. Reads website sales automatically from:
   - Firestore purchaseLogs
   - Render premiumOrders admin export
3. Manual receipts are stored in existing Firestore collection: receipts
   - source = admin-manual-sale
   - Uses the existing receipts security rule; no new Firestore collection is required.
4. Manual receipt supports multiple items.
5. Item categories:
   - Physical
   - Software
   - Service
   - CAD Tools
   - PA/BM
   - Other
6. Automatic calculations:
   - Subtotal
   - Discount
   - Shipping charged to customer
   - Customer total / gross sales
   - Product cost
   - Shipping cost
   - Payment fee
   - Commission
   - Other cost
   - Total cost
   - Net profit
7. Sales totals count Paid records only.
   Pending, Refunded, Cancelled and Failed records are excluded from gross sales and profit.
8. Summary cards:
   - Paid Gross Sales
   - Total Costs
   - Net Profit
   - Physical Sales
   - Software / Digital
   - Pending Records
9. Search and filters:
   - Customer / receipt / product
   - Category
   - Status
   - Source
   - Date range
   - Sort by date, gross, profit or customer A-Z
10. Actions:
   - Create manual receipt
   - Edit manual receipt
   - Delete manual receipt
   - Print / Save as PDF
   - WhatsApp receipt summary
   - Export filtered records to CSV
11. Website-generated payment records are read-only in this tab.
    Existing Payment Logs remains the technical control area for website payment records.

DEPLOYMENT
- Upload the full Patch 721 website to GitHub.
- No Cloudflare Worker change is required.
- No new Render environment variable is required.
- Existing Firebase Admin login and receipts rules must remain active.
