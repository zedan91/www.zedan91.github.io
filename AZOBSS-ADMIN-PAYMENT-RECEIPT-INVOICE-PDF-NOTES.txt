AZOBSS PATCH (306) - ADMIN PAYMENT RECEIPT / INVOICE PDF
Date: 2026-06-23
Baseline: (305)-AZOBSS-ADMIN-PAYMENT-NOTIFICATION-CENTER-FIX_20260623.zip

Purpose
- Add professional receipt/invoice generation for Admin Payment Logs.
- Cover PA/BM purchaseLogs plus Software/CAD premiumOrders.
- Allow admin to view receipt, download PDF, and email PDF receipt to buyer.

Changed Files
- admin/index.html
- deploy-server.js
- README.md
- README_ALL_IN_ONE_RENDER.md

Admin UI
- Payment Logs rows now include:
  - Receipt
  - PDF
  - Email Receipt
- Payment Details modal also includes the same receipt actions.

Backend Endpoints
- GET /api/admin/payment-receipt/:id?source=premiumOrders|purchaseLogs&format=html|pdf
  - Admin protected.
  - Supports HTML receipt view and PDF receipt/invoice.
- POST /api/admin/payment-receipt-email
  - Admin protected.
  - Sends PDF receipt attachment to buyer email or manually entered email.
- GET /api/premium/receipt/:orderId?rt=...&format=pdf
  - Customer Software/CAD receipt now supports PDF format using the existing secure receipt token.

Security
- Admin receipt endpoints require admin auth.
- Customer premium receipt still requires receipt token when required.
- ToyyibPay Software/CAD receipt remains locked until payment is API verified.

Notes
- Firebase Rules update is not required because receipt generation uses backend/Admin SDK and existing admin auth.
- Render backend deploy is required because deploy-server.js changed.
- GitHub Pages deploy is required because admin/index.html changed.
