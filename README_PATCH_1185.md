# AZOBSS Patch 1185 — PC Build Sendiri Compatibility Lock

Build Sendiri kini menggunakan compatibility lock sebenar.

- Intel dan AMD adalah mutually exclusive. Bila satu platform dipilih, CPU/motherboard platform lawan dinyahaktifkan.
- Motherboard ditapis ikut socket sebenar: LGA1700, LGA1851, AM4, AM5 serta asas workstation LGA4677/sTR5.
- RAM DDR4/DDR5 ikut motherboard dan tidak boleh dicampur.
- Cooler ditapis ikut kelas cooling CPU dan radiator 360mm ikut sokongan casing.
- Motherboard form factor mesti muat dalam casing.
- PSU yang terlalu rendah untuk GPU dinyahaktifkan; GPU terlalu berat untuk PSU semasa juga dinyahaktifkan.
- SSD Gen5 ditapis apabila motherboard diketahui tidak menyokong Gen5.
- CPU tanpa integrated graphics memerlukan GPU.
- Kategori single-choice tidak lagi mempunyai butang tambah baris.
- Carian global dan modal setiap kategori menunjukkan item tidak serasi sebagai disabled dengan sebab yang jelas.
- State/preset/share lama yang bercampur Intel+AMD dibersihkan automatik dengan CPU sebagai pilihan utama.

Semua fungsi harga live, markup, 29 kategori, quote/share, bookmark build siap dan admin-only source kekal.
