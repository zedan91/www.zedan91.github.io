# PA Downloader PA Downloader digunakan untuk jana link muat turun Pelan Akui JUPEM berdasarkan nombor PA dan negeri. ## Format URL ```text https://ebiz.jupem.gov.my/MuatTurunPembelian/MuatTurunPelanAkui?noPa=PA{NO_PA}.TIF&negeri={NEGERI} ``` Contoh negeri yang ada space akan di-encode dalam URL: ```text WILAYAH PERSEKUTUAN LABUAN WILAYAH%20PERSEKUTUAN%20LABUAN ``` ## GitHub Pages GitHub Pages boleh buka link TIF asal sahaja. ## PDF Auto Convert Auto convert TIF ke PDF memerlukan backend PHP dengan extension `Imagick`.
