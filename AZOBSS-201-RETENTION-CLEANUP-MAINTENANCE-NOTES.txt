Patch 201: Admin Retention Cleanup Maintenance

Added safer retention cleanup tools to Admin Dashboard > Maintenance.

New maintenance scan checks:
- Expired premium download tokens older than retention
- Admin audit logs older than retention
- Notifications older than retention

New maintenance actions:
- prune-expired-download-tokens
- prune-old-audit-logs
- prune-old-notifications

Optional Render ENV:
- AZOBSS_DOWNLOAD_TOKEN_RETENTION_DAYS=90
- AZOBSS_AUDIT_LOG_RETENTION_DAYS=365
- AZOBSS_NOTIFICATION_RETENTION_DAYS=180

Defaults are used automatically if ENV is not set.
No Firebase Rules update required because backend uses Firebase Admin SDK.
