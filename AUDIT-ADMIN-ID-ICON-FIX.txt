AUDIT RINGKAS - ADMIN ID ICON

Punca utama kenapa perubahan sebelum ini tidak jalan:
1. Handler klik untuk icon Product ID berada SELEPAS </html>, jadi browser boleh abaikan/anggap markup tidak sah.
2. Product ID masih dipaparkan sebagai teks biasa dalam card melalui product-meta.
3. Admin action sebelum ini masih flex row/bottom, bukan column icon menegak di kanan card.

Patch ini:
- Pindahkan handler copy Product ID ke dalam HTML sebelum </body>.
- Sembunyikan product-meta ID dalam card.
- Paksa admin action Software jadi icon menegak, dan 🆔 berada bawah 🗑️ Delete.
- Hanya admin nampak kerana renderer sedia ada masih guna isAdmin().
- PA/BM tidak disentuh.
