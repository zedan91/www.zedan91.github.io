AZOBSS ADMIN DASHBOARD MODULE V1

Added:
- New standalone admin module: /admin/index.html
- Admin-only dashboard with sidebar tabs:
  Overview, Users, Online Users, Activity, Support Inbox, Notifications, Purchase Records, Lucky Draw, Settings.
- Admin topbar button injected for admin users only.
- Firestore quota-friendly loads:
  Users latest 50
  Online users latest 50
  Login history latest 50
  Guest history latest 50
  Support latest 50
  Notifications latest 50
  Purchases latest 50

Firebase Rules:
- No new rules required if current admin read/write/delete rules are already published.
- Existing rules must allow admin read for users, onlineUsers, loginHistory, guestHistory, supportMessages, notifications, purchaseLogs, purchaseSummaries.

Important:
- Homepage admin blocks are NOT removed yet in this v1 to avoid breaking existing scripts.
- This module is separate and safe. After confirming /admin/ works, old homepage admin blocks can be hidden/removed in v2.
