# AZOBSS v1442 — Software Affiliate Offer CTA

Baseline: v1441.

## Changes
- Software Tools affiliate/external purchase cards no longer say `Download Now`.
- Affiliate offer CTA is `Lihat Tawaran`.
- Adds customer disclosure: `Pautan affiliate • pembelian dibuat di laman rakan niaga`.
- Bitdefender cards are recognised as affiliate offers; explicit affiliate flags / affiliate URL parameters / `Lihat Tawaran` button text are also recognised.
- Direct-download software continues to show its existing download CTA.
- Affiliate offer clicks are not counted as software downloads.
- Affiliate links use `rel="noopener sponsored"`.
- Global version badge bumped to v1442.
