# AZOBSS Patch 917 — Rujukan Radius Peta Lot Kadaster

Tarikh: 15 Ogos 2026

Perubahan:
- Menambah satu butang **Rujukan Radius** pada panel kanan `Peta Pilihan Lot Kadaster`, di antara ringkasan kawasan dan harga.
- Tekan butang, klik titik pusat pada peta, gerakkan tetikus untuk pratonton, kemudian klik titik tepi bulatan untuk menetapkan radius.
- Bulatan rujukan berwarna biru/cyan dan berbeza jelas daripada polygon/segi empat pilihan lot.
- Paparan rujukan menunjukkan Radius, Diameter, luas dalam m², hektar dan ekar.
- Label radius + hektar + ekar turut dipaparkan terus pada bulatan di peta.
- Rujukan radius hanya untuk anggaran visual; ia tidak mengubah polygon pilihan, lot, nisbah syit atau harga.
- `Padam Pilihan` turut membersihkan rujukan radius. Tekan Escape ketika mode radius aktif hanya membatalkan radius dahulu dan tidak menutup modal.
- Cache version `azobss-lot-selection-map.js` dinaikkan ke `v=917`.
