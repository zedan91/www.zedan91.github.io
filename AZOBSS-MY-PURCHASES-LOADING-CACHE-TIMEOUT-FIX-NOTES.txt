AZOBSS My Purchases Loading Cache Timeout Fix (381)

Masalah:
- My Purchases kerap tersangkut pada "Loading purchases..." bila Render backend free sedang wake up, Firebase/backend lambat, atau banyak refresh event berlaku serentak.

Fix:
- Tambah backend fetch timeout 9 saat.
- Tambah local cache untuk rekod paid terakhir.
- Kalau backend lambat, paparkan rekod cache dan mesej ringan, bukan loading tanpa henti.
- Elak multiple duplicate refresh request serentak.
- Auto-refresh selepas download dibataskan/debounce.

Firebase Rules:
- Tidak perlu update.

Render ENV:
- Tidak perlu tambah ENV baru.
