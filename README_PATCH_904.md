# AZOBSS Patch 904 — Muat Turun AnyDesk untuk Bantuan Windows Online

- Menambah panel muat turun khas apabila pelanggan memilih **Bantuan Windows Online**.
- Menyertakan `AZOBSS_AnyDesk_Remote_Support.bat` pada halaman Tempah Servis IT.
- Menambah panduan pelanggan untuk menjalankan fail sebagai Administrator, menghantar alamat AnyDesk dan menerima sambungan secara manual.
- Menjelaskan bahawa kawalan hanya bermula selepas pelanggan menerima sambungan.
- Memaparkan amaran tentang clean reinstall AnyDesk, tetapan start bersama Windows, pemadaman ID/tetapan lama, print driver dan kandungan TEMP.
