AZOBSS Frontend API Auth Compatibility Fix (188)

Purpose:
- After backend APIs were hardened, frontend admin/staff actions must include Firebase ID tokens.
- Protected API failures should show friendly messages instead of silent empty lists or raw backend errors.

Changed:
1. admin/index.html
   - Added azAdminAuthHeaders() and azAdminFetchJson().
   - Commission fallback API now sends Authorization: Bearer <Firebase ID Token>.
   - Retries once with a refreshed token on 401/403.
   - Shows friendly API notice for session expired, admin permission required, rate limits and pending verification.

2. staff/index.html
   - Added azStaffAuthHeaders() and azStaffFetchJson().
   - Share-link commission fallback API now sends Firebase ID token.
   - Retries once with refreshed token on 401/403.
   - Shows friendly notice if backend API blocks/rejects request.

3. CAD-Tools-&-Resources/index.html
   - /api/premium/complete-purchase now sends Firebase ID token.
   - Manual complete purchase button is hidden for non-admin sessions because endpoint is now admin-protected.
   - Friendly errors added for 401/403/429/pending verification.

Firebase Rules: no change required.
Render ENV: no new required ENV.
