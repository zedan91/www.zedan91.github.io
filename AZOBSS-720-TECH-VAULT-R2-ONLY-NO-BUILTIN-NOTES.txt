AZOBSS PATCH 720 — TECH VAULT R2 ONLY / REMOVE BUILT-IN FILE

Changes
- Removed the encrypted built-in AZOBSS_Installer.bat copy from the website package.
- Tech Vault now lists and downloads only files stored in Cloudflare R2.
- Every displayed file can be selected and deleted.
- Removed the local bundled-file download endpoint and bundled decryption code.
- AZOBSS_TECH_VAULT_BUNDLED_FILE_KEY is no longer required and may be deleted from Render.
- Existing password login, upload, search, A-Z sorting and bulk deletion remain unchanged.

Deployment
1. Upload this website patch and redeploy the Render backend.
2. No Cloudflare Worker change is required; Worker Patch 719 remains compatible.
3. Keep AZOBSS_TECH_VAULT_PASSWORD, AZOBSS_TECH_VAULT_SESSION_SECRET, AZOBSS_R2_DOWNLOAD_BASE_URL and AZOBSS_R2_TOKEN_SECRET.
