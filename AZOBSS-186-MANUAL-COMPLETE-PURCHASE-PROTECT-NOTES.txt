AZOBSS 186 - Manual Complete Purchase Protect

What changed:
- Protected POST /api/premium/complete-purchase.
- This endpoint can create a PAID premium order and download token without ToyyibPay, so it must not be public.
- Now it requires either:
  1) Firebase admin ID token, or
  2) AZOBSS_ADMIN_API_SECRET / AZOBSS_COMMISSION_API_SECRET via x-admin-key, x-api-key, x-azobss-api-key or Bearer token.
- Added rate limit for /api/premium/complete-purchase.
- Saved completedByUid / completedByUsername / completedByAuthMethod on manual completed orders.
- New manual completed orders also require receipt token by default.

Emergency only:
- AZOBSS_ALLOW_PUBLIC_COMPLETE_PURCHASE=1 reopens old public behavior.
- Do not set this in production unless debugging an urgent issue.

Firebase Rules:
- No update required. Backend uses Firebase Admin SDK.

Render ENV:
- No new mandatory ENV.
- Recommended if using manual complete from external admin tools: AZOBSS_ADMIN_API_SECRET.
