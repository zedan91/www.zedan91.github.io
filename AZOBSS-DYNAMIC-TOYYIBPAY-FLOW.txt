AZOBSS Dynamic ToyyibPay Payment Flow

Updated:
1. Open Payment
2. Complete Payment
3. Payment Verified
4. Download Ready

What changed:
- Open Payment now calls backend endpoint /api/toyyib/create-bill.
- Backend creates a new ToyyibPay bill using the product price from the website.
- Amount is converted to sen automatically: RM1 = 100, RM5 = 500, RM25 = 2500.
- Payment opens in the same tab using window.location.href.
- Backend can receive returnUrl from the current page, so ToyyibPay can redirect buyer back to the last visited AZOBSS page.
- Guest buyer must enter Buyer Email Address before Open Payment.
- Logged-in users do not see the email box.

ToyyibPay dashboard recommendation:
- Multi Payment: Yes
- Fix Amount: No for reusable/dynamic payment setup
- Status: Active
- FPX: Enable
- DuitNow QR: Enable if wanted

Render env needed:
- TOYYIB_SECRET_KEY
- TOYYIB_CATEGORY_CODE
- PUBLIC_BASE_URL
- FRONTEND_BASE_URL
- SMTP_HOST
- SMTP_PORT
- SMTP_USER
- SMTP_PASS
- MAIL_FROM
