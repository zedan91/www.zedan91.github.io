# AZOBSS Patch 896 — AM/PM Time Format

## Admin > Software Key

- Paparan masa ditukar daripada singkatan locale Melayu seperti `PG` dan `PTG` kepada format `AM` dan `PM`.
- Contoh paparan baharu: `Masa 8:21 PM`.
- Tarikh kekal menggunakan format Malaysia.
- Tarikh dan masa dalam Export CSV turut menggunakan format `AM/PM` supaya konsisten.
- Susunan kad menegak, empat medan sebaris dan pagination tiga rekod daripada patch 895 dikekalkan.
