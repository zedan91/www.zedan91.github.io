Common Speed Range

StorageRead / Write RangeNote
HDD80 - 160 MB/sSlow but okay for backup
SATA SSD400 - 550 MB/sGood for normal Windows
NVMe Gen31500 - 3500 MB/sFast for gaming and work
NVMe Gen43500 - 7500 MB/sVery fast
NVMe Gen58000 - 14000 MB/sHigh-end, needs good cooling

Slow Disk Warning Signs

  • Windows boot takes too long.
  • Apps open slowly even with enough RAM.
  • Disk usage always 100% in Task Manager.
  • CrystalDiskInfo health is caution/bad.
  • SSD temperature too high can cause speed drop.
