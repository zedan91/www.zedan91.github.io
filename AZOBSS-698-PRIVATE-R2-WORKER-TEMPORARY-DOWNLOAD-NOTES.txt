AZOBSS Patch 698 - Private Cloudflare R2 Worker Temporary Download

Baseline: Patch 697

Changes:
- Backend generates HMAC-signed temporary Worker links for migrated premium files.
- Link payload contains only R2 object key, safe filename, expiry, session ID and order ID.
- Default temporary link TTL: 7200 seconds (2 hours).
- R2 HEAD preflight confirms signature and object existence before one-time quota is consumed.
- IDM Range/Resume and multiple connections are served directly by Cloudflare R2 Worker.
- Existing secure backend stream remains as fallback for products not yet mapped to R2.
- Supports AZOBSS_DOWNLOAD_SESSION_TTL_MS and existing AZOBSS_DOWNLOAD_SESSION_TTL.

Required Render environment variables:
AZOBSS_R2_TOKEN_SECRET=<same exact secret as Cloudflare Worker>
AZOBSS_R2_DOWNLOAD_BASE_URL=https://azobss-download-gateway.zedan9107.workers.dev
AZOBSS_R2_TOKEN_TTL_SECONDS=7200

Optional:
AZOBSS_R2_PREFLIGHT_HEAD=1
AZOBSS_R2_OBJECT_MAP={"product-id-or-normalized-name":"software/File.exe"}
