  1. Model penuh laptop / motherboard / desktop.
  2. RAM sekarang: DDR1/DDR2/DDR3/DDR3L/DDR4/DDR5, kapasiti, DIMM/SO-DIMM dan speed jika diketahui.

  4. Untuk GPU: model PSU, wattage dan saiz casing.
  5. Untuk bateri/adapter: model laptop atau part number.
