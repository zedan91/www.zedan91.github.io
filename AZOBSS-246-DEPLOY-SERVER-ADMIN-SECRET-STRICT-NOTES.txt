AZOBSS PATCH 246 - DEPLOY SERVER ADMIN SECRET STRICT FIX

Purpose:
- Harden deploy-server.js admin backend routes after ADMIN_KEY was introduced.
- Admin backend endpoints now require ADMIN_KEY / AZOBSS_ADMIN_API_SECRET.
- Firebase profile role alone is no longer accepted for deploy-server admin backend actions.

What changed:
1. azAdminIdentityFromRequest(req, parsed) now returns null unless the request carries the configured admin secret.
2. If the admin secret is valid and Firebase Authorization is also present, Firebase identity is used only for audit/log context.
3. If no Firebase token is present but the secret is valid, the request is treated as api-secret admin.

Not touched:
- Cart / Like / Bell / Message badge.
- My Purchases.
- PA/BM paid/verified user download logic.
- Firestore Rules.

Required environment:
- Render must keep one ADMIN_KEY row only.
- Admin Dashboard browser must save the same key in Settings > Backend Admin Key.
