AZOBSS 530 - Software Share Link Card Layout Match Fix
Date: 2026-07-20
Baseline: (529)-AZOBSS-HOME-SOFTWARE-PROMO-SLIDER-FIX_20260720.zip

Scope
- Software-Tools/index.html only.

Problem
- Shared product URLs could show an older card copied from the 48-hour local first-paint cache.
- The shared-product DOM filter ran after virtual pagination, while only the current eight cards exist in the DOM.
- This could leave the shared view using stale spacing/description markup and omit the current More button even though the normal Software Tools link used the latest renderItem() template.

Fix
1. Shared-product URLs no longer inject the old local first-paint card cache.
2. The shared Product ID is resolved at the software data layer before virtual pagination.
3. The requested product is rendered using the same current renderItem() template as a normal visit.
4. The temporary shared first-paint lock is released after the real matching card is rendered.
5. Normal Software Tools browsing, pagination, download, share, likes, cart, admin controls and payments are unchanged.

Deployment
- Frontend/GitHub Pages only.
- No Firebase Rules update.
- No Render redeploy required.
