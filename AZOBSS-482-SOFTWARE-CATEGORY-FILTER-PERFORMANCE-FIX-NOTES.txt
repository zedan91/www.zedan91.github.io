AZOBSS PATCH 482 — SOFTWARE CATEGORY FILTER PERFORMANCE FIX
Date: 2026-07-17
Baseline: (481)-AZOBSS-SOFTWARE-HERO-TITLE-DESCRIPTION-REMOVE-MOVE-UP-FIX_20260717.zip

Problem
- Software Tools contains about 627 software records.
- Every category/platform/search selection previously deleted and rebuilt hundreds of complex software cards.
- Admin account filtering, category totals, stats parsing and pagination layout checks were also repeated on every click.
- This caused a noticeable pause when selecting categories inside grouped dropdowns.

Fixes
- Added a reusable DOM card pool: software cards are built once and then hidden/shown on filter changes.
- Reuses card elements instead of destroying and recreating all cards.
- Caches deduplicated software data until source data changes.
- Caches category statistics until software data changes.
- Caches the admin owner-account filter until software data changes.
- Uses one software-stats snapshot per filter pass instead of repeatedly parsing localStorage.
- Refreshes visible card statistics without rebuilding the whole card.
- Pagination now respects filter-hidden pooled cards.
- Removed forced computed-style reads for hundreds of dynamic cards.
- Added content-visibility containment for off-screen pooled cards.
- Existing category dropdown, platform/type filters, sorting, search, pagination, premium purchase, likes, ratings and admin functions are retained.

Deployment
- Firebase Rules update: NOT REQUIRED.
- Render/backend deploy: NOT REQUIRED.
