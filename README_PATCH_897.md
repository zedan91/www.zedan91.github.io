# AZOBSS Patch 897 — PC Name Aligned With PC Specification

## Admin > Software Key

- Nama komputer seperti `USER` dan `ADMINISTRATOR` tidak lagi menggunakan baris tersendiri di bahagian atas kad.
- Nama komputer kini diletakkan pada baris yang sama dengan spesifikasi `PC: Manufacturer • Model`.
- Baris tersebut turut mengekalkan Record ID di bahagian yang sama.
- Pada skrin kecil, baris boleh turun secara responsif supaya teks tidak terpotong.
- Format masa `AM/PM`, kad menegak, empat medan sebaris dan pagination tiga rekod daripada patch terdahulu dikekalkan.
