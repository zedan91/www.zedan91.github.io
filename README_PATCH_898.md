# AZOBSS Patch 898 — Dark Software Key Cards

## Admin > Software Key

- Latar kad Software Key putih ditukar kepada gradient biru gelap seperti tema jadual Admin.
- Kotak `System ID`, `Systemcode`, `Motherboard ID` dan `Key Serial` menggunakan latar navy yang lebih gelap.
- Warna label, nilai, metadata, butang Copy dan garisan sempadan dilaraskan untuk kontras yang jelas.
- Badge pelanggan, telefon, status lengkap dan status menunggu menggunakan warna gelap yang sepadan.
- Kad rekod kosong turut menggunakan tema gelap.
- Susunan nama PC sebaris dengan spesifikasi, format masa `AM/PM`, empat medan sebaris dan pagination tiga rekod dikekalkan.
