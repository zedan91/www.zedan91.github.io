AZOBSS (511) Public PA RM50 Purchase

- New /Beli-Pelan-Akui/ page for guests and ordinary users without PA/BM access.
- New navbar tab injected by azobss-global-auth.js; hidden for PA/BM members, admin, staff and semi-admin.
- Public price is locked at RM50 / 5000 sen in both deploy-server.js and backend/server.js.
- One PA per bill. Backend validates PA number, state, buyer email/phone and checks PA existence before creating ToyyibPay bill.
- Paid purchase is written to purchaseLogs with 5 downloads / 7 days.
- Payment return verifies with ToyyibPay API before exposing the controlled PDF link.
- Download link and receipt are shown on the page and emailed to the buyer.
- This purchase does not change PA/BM allowed status.
- Render backend redeploy is required. Firebase Rules update is not required because backend writes use Firebase Admin.
