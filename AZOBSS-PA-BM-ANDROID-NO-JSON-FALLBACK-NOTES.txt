Patch 208 - PA/BM Android no JSON fallback download fix

Fixes Android/mobile browsers saving JUPEM fallback JSON as *.pdf.json.

Changes:
- PA/BM fallback no longer returns application/json on GET.
- Backend returns an HTML redirect/interstitial page with X-AZOBSS-Browser-Fallback headers.
- The HTML page auto-opens the original JUPEM link and includes a manual button.
- Frontend detects X-AZOBSS-Browser-Fallback from fetch and opens X-AZOBSS-Open-Url directly.
- Prevents blob-saving fallback HTML/JSON as a PDF.

No Firebase Rules update required.
No required Render ENV.
