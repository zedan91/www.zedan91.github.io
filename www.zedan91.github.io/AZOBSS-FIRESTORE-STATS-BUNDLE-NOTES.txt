AZOBSS Firestore 1 Document Software Stats Bundle

Implemented in: Software-Tools/index.html
Firestore path: settings/softwareStats

Purpose:
- Download and rating stats no longer reset when deploying a new ZIP.
- Page load uses 1 Firestore document read only.
- Download click updates only items.<productId>.downloads using increment(1).
- Rating uses transaction so 1 browser voter token can rate each software once; re-rating replaces old rating.

Important:
Deploy Firestore rules that allow public read/create/update for settings/softwareStats, or the frontend will fall back to local cache only.
Updated rule snippets are included in the FIREBASE-RULES files in this ZIP.
