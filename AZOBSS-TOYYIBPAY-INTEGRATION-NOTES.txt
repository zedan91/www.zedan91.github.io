AZOBSS ToyyibPay Integration

Implemented in this package:
- Software premium Buy Now can create ToyyibPay bill from backend.
- Secret Key is read from Render Environment Variables, never from frontend.
- Category Code default must be set in Render.
- ToyyibPay callback updates pending order to paid.
- After payment is paid, backend generates temporary secure download token and receipt URL.
- Frontend button: Open Payment Link -> pay ToyyibPay -> Check Payment / Unlock Download.

Render Environment Variables required:
TOYYIB_SECRET_KEY=<your ToyyibPay Secret Key>
TOYYIB_CATEGORY_CODE=wqrblyk7
PUBLIC_BASE_URL=https://azobss-backend.onrender.com
FRONTEND_BASE_URL=https://www.azobss.com

Optional:
TOYYIB_BASE_URL=https://toyyibpay.com
TOYYIB_RETURN_URL=https://azobss-backend.onrender.com/api/toyyib/return
TOYYIB_CALLBACK_URL=https://azobss-backend.onrender.com/api/toyyib-callback
TOYYIB_SANDBOX=false

Important:
- Do not put TOYYIB_SECRET_KEY in GitHub, HTML, JS, or Firebase.
- If you regenerate ToyyibPay secret key, update Render env variable.

Firebase Rules:
Your uploaded rules already contain orders/receipts/downloadTokens sections. No extra rule is required just for the backend JSON order/token flow.
If you later want backend to write orders into Firestore via Admin SDK, add Firebase Admin service account env and keep existing orders/receipts rules for frontend display.
