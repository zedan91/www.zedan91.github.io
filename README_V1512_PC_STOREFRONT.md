# Website (1512): PC, Laptop & Components

Based on the complete owner archive (1511), preserving PC Build photo editing,
GitHub publishing, existing orders/authentication and unrelated website features.

The expanded storefront adds exact variants from six official sources: DOTATECH,
EMARQUE, ALL IT Hypermarket, Brightstar, NB Plaza and ILLEGEAR. At packaging the
import contains 5,061 eligible photo-approved variants plus seven original photos.
Availability is not a real-time supplier guarantee. Some feeds are partial due to
429 responses; IdealTech, TechHypermart and Jayacom reject requests with 403,
and Viewnet has no usable current public feed. This is not every product at all
10 suppliers. No supplier access restrictions were bypassed.

Customers can search, filter category/brand, sort, paginate (24 cards), zoom photos,
read specifications, select quantity, Add to Cart, Buy Now and view their orders.
Product photos retain the whole canvas and genuine manufacturer marks. Retailer
logos, price artwork and incompatible variant photos are quarantined instead of
cropped or erased. OCR screening plus visual sampling cannot guarantee perfect
logo recognition; retain the owner photo-editing workflow for corrections.

Markup formula remains unchanged: 15/12/10/9/8/7 percent at cost thresholds
2500/4000/6000/8000/10000 MYR, minimum RM250 for systems / RM150 components,
rounded upward to the next RM10. Server-controlled prices ignore client totals.
Only selected checkout products are rechecked; browsing does not scrape thousands
of products. Missing or unavailable pinned Shopify variants cannot be substituted.
Imported items require manual price/stock/configuration confirmation before
invoice/payment. Existing Maybank/receipt and admin order processing remain.
This change does not place or fulfil supplier purchases automatically.

Static snapshot renders while the backend connects, then merges compatible data.
Snapshots expire after 14 days. Refresh at least weekly using tools/pc-storefront
(Windows offline OCR). Run the owner refresh helper, review photos and audit reports,
then test/package the full website. No automatic refresh schedule was created.
Raw costs live only in the server catalogue; public storefront JSON exposes selling
prices. The full source is owner source, not a secrets store; supplier prices are
already public. Do not add private credentials or customer data.

Verification: 43 targeted PC Shop tests; isolated browser checkout, quantity/cart,
responsive view and exact-photo checks. No production payments/customer orders.
