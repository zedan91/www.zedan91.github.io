# AZOBSS v1336 — Quotation → Invoice → Receipt

- Adds Quotation / Sebut Harga to Admin > Sales & Receipts.
- Flow: Quotation → Invoice → Payment → Receipt.
- Quotation statuses: Draft, Sent, Accepted, Rejected, Expired.
- Adds All / Quotations / Invoices / Pending Payment / Paid / Receipts view buttons.
- Adds Quotation PDF support with AZQ document number and optional Valid Until date.
- Accept and Convert to Invoice actions are available on quotation rows.
- Quotation does not count as sales/profit and does not create payment QR or commission sync.
- Existing invoice, deposit, receipt, ToyyibPay, Maybank, website override and receipt-delivery flows are preserved.
