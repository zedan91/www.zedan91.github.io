Firefox Bridge 1.3.4

Pemasangan kekal melalui XPI bertandatangan Mozilla. Versi ini mengenal pasti paparan PDF Adobe Acrobat dalam WhatsApp Web dan mengisi nota dalam ruang Type a message di preview.

Pasang Firefox Bridge 1.3.4

  1. Disable/remove bridge lama pada Add-ons and themes → Extensions untuk menghentikan queue lama. Jangan padam mesej WhatsApp; semak atau batalkan preview lama secara manual jika masih ada.
  2. Pasang XPI baharu dalam Firefox. Jika ia dimuat turun sebagai fail, pilih gear pada Add-ons Manager → Install Add-on From File…. Sahkan versi 1.3.4.
  3. Refresh kedua-dua tab Admin dan WhatsApp. Gunakan profil/private/container yang sama. Untuk private window, extension perlu mempunyai izin private jika anda mahu menggunakannya di situ.

Tidak perlu pemasangan sementara, about:debugging atau mematikan semakan tandatangan. Penyediaan PDF dengan kapsyen automatik memerlukan versi 1.3.4.

Popup tidak menutup ruang taip

Notis berada di bahagian atas dan membenarkan klik pada chat di belakangnya. Notis kejayaan hilang sendiri selepas kira-kira 3.5 saat; notis ralat hilang selepas kira-kira 8.5 saat. Butang × boleh menutupnya lebih awal.

Satu PDF bersama nota

Bridge memilih input Document, mengesan preview baharu termasuk nama fail yang dipendekkan dan caption dalam preview di ruang chat. Nota quotation/invoice/resit disemak selepas diisi. Draf anda tidak ditimpa. Semak penerima, PDF dan caption, kemudian tekan Send sendiri.

Jika preview atau caption masih tidak dapat disahkan, proses berhenti selepas satu percubaan. Jangan ulang lampiran sebelum menyemak WhatsApp. Gunakan Copy Message dan tampal pada caption secara manual jika perlu. Tiada auto-Send atau retry fail automatik.

Chrome/Edge tanpa plugin

Chrome / Edge — no add-on: sediakan PDF, kemudian klik sekali lagi untuk system share jika disokong. Pilih app dan pelanggan sendiri. Existing WhatsApp tab — no add-on: muat turun satu PDF, copy nota, beralih ke tab WhatsApp sedia ada dan lampirkan secara manual. AZOBSS tidak membuka tab WhatsApp tambahan.

Laman biasa tidak boleh mengawal tab WhatsApp lain yang dibuka manual tanpa bridge. Ujian menggunakan profil terpencil dan data rekaan; aliran akaun WhatsApp pelanggan yang sedang login belum diuji secara langsung. Pemasangan dalam profil Firefox anda perlu dibuat sendiri.
