AZOBSS Patch 703
R2-only Download Email Secure Link Fix
Date: 31 July 2026

Baseline:
- Patch 702

Fixes:
1. Paid Software/CAD products that use only Cloudflare R2 Private Object Key no longer fail email delivery with "Premium Download File Link missing".
2. The backend now accepts either:
   - an HTTPS Premium Download File Link, or
   - a valid Cloudflare R2 Private Object Key.
3. The raw r2ObjectKey is never inserted into the buyer email.
4. The buyer receives only the secure AZOBSS confirmation URL:
   /api/premium/download/<temporary-token>
5. The paid order and download token are hydrated with the trusted current product R2 object key before email/token generation.
6. Admin receipt-email resend can now generate or repair secure download tokens for R2-only products.
7. Manual/admin complete-purchase now also supports R2-only products.
8. PA/BM email and download flows are unchanged.

Expected flow:
Buy Now -> payment verified -> backend creates/repairs secure token -> email contains AZOBSS Download Now link -> Start Download -> temporary Cloudflare Worker R2 link.
